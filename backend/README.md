# Backend

Ten katalog jest przeznaczony na przyszły kod backendu aplikacji.

Obecnie strona jest frontendem React/TypeScript. Prywatne zdjęcia do analizy oraz
kopie wdrożeń są przechowywane poza repozytorium w zabezpieczonym katalogu
`private-data` na serwerze. Lokalne dowiązania zachowują dotychczasowe ścieżki,
ale są wykluczone przez główny plik `.gitignore`.
